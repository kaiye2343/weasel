# Rime 皮肤设计器

预览参数可切换“皮肤原始参数”和“实际显示偏好”。后者默认与设置中心相同的 12／10 pt、紧凑密度；个人设置可从设置中心皮肤页导出 JSON，再在网页导入。此设置只改变预览，不改写导出皮肤。图片锚点统一以可见框体四角为准，不包括原生窗口的阴影画布。

解压完整目录，双击 **index.html**。建议使用较新的 Edge 或 Chrome；无需安装、联网、账号、开发服务器或 Node.js。网页不会连接输入法，也不读取词库。未导出的设计在关闭页面后不会保留。

## 使用

1. 在「皮肤信息」设置名称、唯一标识、作者、版本与能力：**仅无注音**或**带注音与无注音**。
2. 选中「输入框」设计字体、背景、边框、九宫格、分隔线和装饰留白。注音使用整条候选已有注释；没有注释时不猜读音。
3. 「添加 PNG 图片」创建图层，拖动定位或调整四角锚点、偏移、容器尺寸、z 顺序。图片等比、居中靠底。框外图片扩展画布；为框内装饰增加留白。
4. 「＋」复制变体，在皮肤信息中修改变体名称与标识。最多 32 个变体，每个最多 8 个图片层。
5. 切换带注音／无注音、部分／整页缺少注音、长短候选以及 100%／150%／200% 预览。两种框高共用自适应背景及图片锚点，九宫格负责伸缩，不需要固定尺寸的候选窗截图。
6. 导出 **.rimeskin**。在包含格式 1.1 支持的新版设置中心导入，先用独立原生预览确认，再启用。网页预览与原生字体测量并非逐像素一致；全局字号、密度和注音偏好可能覆盖皮肤默认值。

支持导入现有 ZIP / .rimeskin（存储或 Deflate）。先校验整个包和所有图片再替换画布，失败保留当前设计。导出重新生成 PNG 预览，只包含被引用素材。Ctrl+Z 撤销最近设计操作；文本输入框内优先保留浏览器的撤销。

## 兼容与限制

- 新建设计为格式 **1.1 / schemaVersion 2**，通过 `annotationSupport: "none" | "both"` 声明能力。**旧版 0.17.4.64 不能导入，需成套更新组件。**
- 导入 1.0 旧包后保持其格式；修改能力选项会升级到 1.1。无独立原始输入拼音行。
- 当前提供同一套自适应框体，不提供两套独立的固定布局模板。两种注音状态的框高、分隔线和图片锚点会自动变化。
- 仅静态 PNG、原生横排候选窗；无动画、脚本、程序插件、内嵌字体。系统应用自行绘制的候选列表不保证显示装饰。
- 安全预算：压缩包 50 MiB／256 条目，展开 100 MiB，单张 2048×2048，活动变体解码 64 MiB。包内仅 PNG 与 JSON，拒绝越界路径、设备名、符号链接、CRC 损坏和重复路径。
- 网页预览的阴影、文字间距与字体度量是近似值；原生预览为最终依据。字体需在 Windows 自行安装。
- 设置中心仅管理皮肤；完整设计编辑在此网页完成。皮肤不会绑定本体名称或守岸人角色。

完整格式说明见随包 `skin-format.md` 和 `rimeskin.schema.json`。示例包在 `samples/`；开发仓库也保留原守岸人可选示例。

## 开发回归

运行 `node tests/designer_test.cjs`（仓库根目录，无依赖）。浏览器回归需要 `npm ci --prefix designer` 和 Playwright 浏览器，再运行 `node tests/designer_browser_test.cjs`；可用 `DESIGNER_BROWSER_CHANNEL=msedge` 选择已安装的 Edge。仅使用隔离 headless 浏览器。

网页运行本身不依赖这些开发工具。遵循仓库 GPL-3.0 许可；示例几何素材由项目代码生成。
