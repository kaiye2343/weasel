# 图片装饰的缺省定位

2026-11-02，用户确认实现并安装。关联 [大小与遮挡现场](issues/2026-10-31-candidate-size-occlusion-regression.md)。

## 行为

- 显示偏好缺失、定位字段省略或 `candidatePlacement: "default"` 时，当前有效样式包含图片装饰层则使用自动避让；无装饰时继续原版定位。九宫格／框内背景本身不视为框外装饰。
- 旧显式 `native`、`auto`、`below`、`above` 与偏移／间距／避让开关保留。设置中心新增“跟随外观（图片装饰自动避让）”，保存后保持这一区别，不将省略项物化成显式 native。
- 每次定位只用当前样式中的图片层是否为空解析默认模式；不在按键路径读配置或摘要、加载／缩放图片，也不改 UIStyle IPC。
- 几何算法保持原实现：仅让与应用锚点水平相交的图片矩形参与上下避让，空间不足换边并限制在工作区。不能保证宿主未提供的完整输入行始终不遮挡，空间不足时也不作此承诺。
- 不改变字号或皮肤内容。守岸人 1.0.1 仍需主动导入／启用；不覆盖用户修改的旧皮肤。

## 验证与交付边界

本机 62 项设计器逻辑、174 项管理器测试通过，覆盖默认与显式 native 的区分、旧字段、缺省读取不写文件、失败回退。原生加载器与纯几何增加对应矩阵；CI 增加 default 模式的装饰预览回归，原有 auto 回归和历史负控制继续保留。

新增 `skin_placement_benchmark.cpp` 使用 0／2／8 层、96／144／192 DPI、native 选择器／跟随外观／显式 auto 做同合成矩形的批次计时，输出每次计算的 P50／P95（纳秒）。其范围仅为默认解析与纯几何，不包含真实 SetWindowPos、IPC、Rime 计算或整帧绘制，不作为实际输入延迟对比或确定性能收益的证明。

没有更改 `.rimeskin` 格式或 UIStyle 序列化；新 `default` 字符串不被旧构建识别。回滚程序前应保留原偏好并将该字段明确选为旧构建支持的 native／auto 等模式，不能宣称旧构建兼容新字段。

完整构建结果及安装后的文件身份／普通用户服务核对待记录。实机输入由用户完成；不以自动回归通过等同于原截图现场通过。
