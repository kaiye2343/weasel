# 扩展词库与订阅

设置中心新增独立页面“扩展词库与订阅”；原有“词库与模型”继续管理 TSV 合并、官方用户快照和 `.gram`，不改变原有入口。

## 使用流程

1. 选择预设萌娘词库（带声调或无声调），或者填写自定义标识、名称与 HTTPS `.dict.yaml` 直链。也可以导入本地文件。
2. 点击下载。校验后先审阅文件变更，再确认备份保存；下载不等于启用。页面不会在打开时联网，没有常驻更新或定时任务。
3. 顶部选择具体方案，点击“启用到当前方案”。工具检查主 `script_translator` 与主词典音节表，检查通过后追加 `translator/packs/+`，不替换主词典、不修改活动 `.userdb`。工作／日常分别启用。
4. 审阅并保存后，使用底部“部署应用”让 Rime 编译。页面显示的启用状态是已保存补丁，不冒充已部署状态。
5. “检查并下载更新”重新下载、比较 SHA256，内容不变不保存；内容变化保留历史版本。已启用词库的更新影响所有引用它的方案，并重新检查这些方案的编码。

词库版本可回退、导出。移除订阅前须先停用，并移除其他 YAML 中的引用；移除会备份注册信息与受管理静态词库，历史下载保留，可通过“备份与恢复”恢复。个人补词应独立保存；检测到 `sub_<id>.dict.yaml` 被手动改动时拒绝覆盖，要求先导出个人改动。

## 数据与边界

- 目录位于所选 Rime 资料根的 `dictionary-subscriptions/<id>/`，包含订阅记录和按摘要保存的原始词库文本；受管理安装文件为资料根的 `sub_<id>.dict.yaml`。
- 每次文件写入沿用 `ConfigurationPlan` / `RimeProfiles` 的变更审阅、备份、并发修改检查和失败回退。SHA256 是规范化 UTF-8 文本的内容标识，不是上游签名认证。
- 下载只发起文件请求，不发送输入正文；HTTPS 重定向最多 6 次，不接受 HTTP 降级、URL 内账号密码或脚本安装包，超时 90 秒。使用系统网络设置，不内置开发代理或凭据。
- 首版只接受 UTF-8、自包含静态 `.dict.yaml`，最多 16 MiB / 50 万词条 / 10 万不同编码。支持 `text`、`code`、可选 `weight`，不执行引用词典、编码器和预设词汇配置。安装文件使用独立名称和受控表头，缓存保留原始来源文字。
- 每订阅最多 100 个历史版本；目前不自动清理历史。备份与历史文件可能较大，变更窗口对大文件只截取预览，保存与备份使用全文。
- 自动挂载只覆盖主 `script_translator` 的简单 `translator/packs/+` 列表；复杂嵌套／引用补丁、其他翻译器、没有源码或不匹配的编码会拒绝挂载并给出原因，仍可下载与导出。不会自动刷音、猜测多音字或转换辅助码。
- 主词典源码校验最多读取 32 个引用、128 MiB；词库编码须属于主词典音节表。这是必要兼容检查，不代表每个角色的读音都正确，也不代表实际候选排序已经验收。

## 来源与验证

预设来源：[suiginko/moetype](https://github.com/suiginko/moetype)，使用其最新 Release 的 `moe.dict.yaml` / `toneless_moe.dict.yaml`。项目仓库不附带或重新发布整份词库，使用者需确认来源许可。

本机已用公开带声调样本验证 204,330 条词条可解析、生成导入预览。该结果不等于与所有万象版本兼容；公开样本与万象字表存在编码差异，记录见 [独立问题单](issues/2026-10-25-moetype-wanxiang-code-compatibility.md)，本轮不自动转换。小型匹配词库的启用、更新、停用、回退及备份恢复由隔离自动测试覆盖。

没有安装或修改日常资料；日常候选效果与新页面的桌面操作由用户验收。
