# 守岸人小狼毫扩展版

官方基础 Weasel 0.17.4（9cc96e2），上游 https://github.com/rime/weasel ，fork https://github.com/kaiye2343/weasel ，工作分支 shorekeeper。

## 通用框架

- PNG 皮肤包、版本并存、变体、可配置配色/边框/九宫格背景/图层/字体/留白/阴影。
- 图片与候选文字由同一个原生窗口合成，无外挂透明窗口。
- 候选注释上方/旁边/隐藏，使用方案原有注释；不猜读音。
- 管理面板按需启动，关闭后不常驻；皮肤选择独立于 Rime 方案和学习数据。
- /skin-reload 通过 IPC 刷新，不部署、不重启算法服务。失败保留当前皮肤。
- 独立预览与输入法共用原生加载、布局、绘制，不连接当前输入会话。

首版仅支持原生横排候选窗；系统应用自行绘制的候选列表不保证装饰。静态 PNG 首发，动画后续处理。皮肤参数说明见 [skin-format.md](skin-format.md)，格式约束见 [rimeskin.schema.json](rimeskin.schema.json)。守岸人包包含棉花娃娃、吃瓜、星蝶三个变体。

## 构建和运行

Actions → Shorekeeper build，或推送 shorekeeper 分支。Windows 2022、VS2022、Boost 1.84、librime 1.13.1、.NET 10；先检查皮肤、配置与同步协议，再构建完整 x64/x86 组件、安装包、原生预览、Windows x64 自包含面板。

下载 artifact 后解压：tools/Shorekeeper.Manager.exe 打开面板，先导入 shorekeeper-1.0.1.rimeskin，再打开原生预览。可传 --data-root 指定独立皮肤资料目录。预览无需安装实验输入法。安装实验版、连接真实 WebDAV 账号分别由用户授权。

守岸人 1.0.1 仅收紧文字区：候选／注音为 12／10 pt，间距 8 DIP，左留白 8、上留白 4 DIP。下留白仍为 12 DIP，保留底部艺术字向框内突出所需的空间。角色、翼光、艺术字和右侧装饰预留保持原样，因此含装饰的总画布不一定变矮。其他包仍按作者尺寸，已有用户字号覆盖仍优先。新版本与 1.0.0 并存；构建或程序升级不会自动改写已安装皮肤，需在设置中心导入并主动启用。用户修改过的旧包不会被覆盖。

产物附提交号和 SHA256。只有 Actions 成功且所需文件存在才算构建通过；构建不能替代真实透明重绘、DPI、跨屏和应用兼容验收。当前验收记录见 [IMPLEMENTATION-STATUS.md](IMPLEMENTATION-STATUS.md)。

本版修改 UIStyle 和 IPC 缓冲区，必须完整安装同一次构建的前端、服务、部署器；不得单独替换 DLL。安装程序沿用上游注册方式，不能与官方版本同时注册。

## 输入与场景

面板提供简繁默认状态、全/双拼、算法纠错、上下文排序、模糊音、快捷短语及 TSV 词库。复用已安装万象 LTS 的脚本；不是微软拼音设置迁移工具。原有模糊音未知规则保留，面板管理自身支持的规则。

新场景复制基础 schema 并配置独立的中文、英文、自动造词、上下文、手动排序、统计数据库和拼写棱镜；词库仍共用。短语使用独立静态词典和依赖方案编译，保留万象公共短语。通过 Rime 方案菜单切换，不重新部署；新建/修改配置和导入词库需要部署。关闭面板不影响输入。

所有写入先备份，多个文件先暂存、完成后提交，出错回滚已提交文件；备份中包含恢复索引。YAML 注释排版可能重排，原文件保留于 backups/shorekeeper。先用独立资料目录验收，不直接修改日常配置。

词库 TSV：每行 词语<Tab>拼音<Tab>可选整数频率。管理器导入当前场景同名 dict.yaml，备份后合并去重。

## 手动 WebDAV

不安装外部常驻同步软件。配套面板提供按需 HTTPS WebDAV，密码可选保存在 Windows 凭据管理器，不写入公开配置或日志。流程：本地快照备份 → 下载并校验各设备快照 → 官方 /sync 合并 → 上传本设备快照 → 条件更新发布指针。绝不覆盖活动 .userdb。每台设备必须有不同 installation_id。

远端 rime-sync/<设备>/<不可变代次>/ 存放快照与可共享配置，latest.json 是最后提交的代次指针。中断保留旧指针；ETag 冲突拒绝覆盖。其他设备配置放在 backups/incoming-config 待审阅，不直接覆盖本机设置。协议和官方 Rime 快照是两个层次：Android 端需要采用同样目录协议或显式转换，不能仅凭支持 WebDAV 就宣称兼容。

坚果云地址 https://dav.jianguoyun.com/dav/ ，使用应用密码。切换自建 HTTPS WebDAV：停用同步、备份双方目录，把完整 rime-sync 目录原样复制到新服务器，修改地址与凭据，先手动同步。需要服务器支持 MKCOL、PROPFIND、GET、PUT、ETag 和条件写入；尚待真实服务验收。

Android 导出包含静态方案、词库、Lua 等，不包含 Windows installation.yaml、活动数据库或语法模型。手机另装兼容 Trime、导入同版本模型并部署；双端合并实机验收后才标记可用。

## 问题1与回滚

问题1：退回全拼、繁体竖排或无法选词。已在原官方程序出现，根因尚未确定。先保存诊断包，包含配置来源、文件哈希、运行日志、进程版本，以及改版服务可提供的实际会话方案与显示状态；不采集输入正文、不自动重启。外观失败不重置方案。

恢复默认外观在面板完成。程序回滚必须退出服务后完整安装官方稳定版，保留学习资料；恢复配置使用 backups/shorekeeper 的原文件。不要在服务运行时覆盖 userdb。当前开发不改写本机 Rime 目录，也未安装实验构建。
