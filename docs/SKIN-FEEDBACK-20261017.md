# 皮肤管理与预览反馈修正

## 范围

用户授权先完成已汇总反馈，再安装完整新版；桌面输入与交互验收由用户本人完成。本轮没有改变输入方案、词库、学习数据库或遗留目录的位置。

## 设置中心

- 新增“移除此版本”，按钮确认后只移除所选版本。当前启用版本移除后恢复原生外观；其他版本继续保留。
- 文件按钮和拖入单个包共用校验／导入流程。同标识同版本弹窗确认覆盖；不同版本弹窗说明并存，不自动切换当前版本。
- 覆盖活动版本保留仍存在的变体；旧变体不存在时选新包首个变体。清除该版本的旧样式覆盖，避免用户导入新设计后仍显示旧样式。
- 原包与选择状态放入皮肤资料根目录 `history/<时间-唯一标识>`，失败时回退原包与状态。支持取消后清理暂存、并发修改锁、路径校验和活动刷新失败回退。目录链接不作为替换或移除目标。
- 新增导出个人网页预览偏好的入口。仅导出字号、密度和注音偏好，不导出词库或凭据。

## 图片位置差异

原生 `_UpdateSkinGeometry` 曾以包含阴影留白的窗口画布定位图片，网页以可见框体定位；相同清单会产生可复现的偏移。现统一为可见框体四角，阴影只参与窗口边界扩展，不参与图片锚点。回归使用非零阴影原点、四角以及旧守岸人包参数验证。

网页新增“皮肤原始参数／实际显示偏好”：实际偏好默认与设置中心一致的 12／10 pt、紧凑密度，可导入个人偏好；预览覆盖不修改导出包。两种布局和两种预览参数下，图片相对框体的偏移保持清单约定。文字使用浏览器字体度量，仍不宣称与 DirectWrite 逐像素相同。

九宫格 PNG 同装饰层一样采用脱离源文件的解码缓存，避免活动皮肤的源文件锁妨碍替换；旧配置中的非皮肤背景图加载方式保持兼容。
