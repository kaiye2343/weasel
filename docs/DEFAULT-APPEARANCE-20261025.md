# 默认外观与原配置兼容

日期：2026-10-25。范围：用户确认默认设置延续小狼毫／原有输入方案配置，新皮肤包保持独立可选；不新增原主题叠图片模式。

## 默认值规则

- 先由小狼毫正常读取原有 YAML 配色、字体及布局。没有主动选择扩展皮肤时，不自动选择示例皮肤，不把万象的 Win11 配置替换为官方 Aqua，也不重置横竖排列。
- 候选已有注释按原配置在后侧显示；默认不额外生成读音或启用上方两行注音。显示开关只控制方案已有注释，长词注音生成仍属于单独的方案设置。
- `display.json` 缺失或为空、字段省略时，字体、间距和注音位置默认 `skin`，含义为跟随当前基础样式：未选择扩展皮肤时是 YAML 样式，已选择时是该包样式。
- 旧文件明确保存的 `above`／`beside`／隐藏、用户字号和紧凑／标准密度继续执行，不推断某个旧值是否曾由软件自动填写。读取不会改写配置，升级不删除皮肤选择或用户偏好。
- 空注音行模式在原生加载器中仅对显式字段覆盖；设置中心保存完整偏好时，会将当前选项（缺省为 collapse）写出。此完整保存的字段物化不等于对所有自定义扩展字段提供持续继承。
- 候选定位增加 `native`，默认使用原有定位分支。`auto`／`below`／`above` 的既有编号和行为不变，仅主动选择这些模式时才应用偏移、最小间距及装饰避让。原定位模式下设置中心禁用附加控件。

## 配置、UI 和兼容

管理器、原生加载器和离线网页默认值同步修改。界面明确显示“跟随原配置／皮肤”“候选后侧”“小狼毫原有定位”。恢复默认显示参数仅恢复显示偏好的继承状态；皮肤管理的恢复原生外观另行控制皮肤选择，两者都不重置方案或学习记录。

本批未改变 `.rimeskin` 格式或 UIStyle IPC 字段。`candidatePlacement: "native"` 为本批新增显示偏好枚举值，旧构建不认识此值，回退使用旧构建前应保留原偏好并改用它支持的 `auto` 等选项；不保证旧版读取新值。完整分发需包含新管理器及 x86／x64 原生组件，应用中仍加载旧前端时不能视作新行为已生效。

没有修改安装目录、日常 Rime 配置、词库、Lua 或学习数据，没有执行桌面输入操作。新默认仅在新构建加载缺省显示偏好时生效；本机仍使用已授权安装的 .158。
