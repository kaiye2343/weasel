# Rime 设置中心

## 定位

Windows 输入法继续基于 Rime／小狼毫；守岸人为独立可选皮肤。设置中心使用中性的 Windows 11 风格，不绑定任何角色。技术命名与旧 `%LOCALAPPDATA%\ShorekeeperWeasel` 存储路径暂时保留，避免丢失已导入的皮肤及选择状态。

本轮参考 [RimeVision](https://github.com/franvz9/Rime_vision) 的功能划分，未直接复制第三方代码。保留上游 Weasel 许可证及已有移植提交作者。

## 模块

- 通用与候选显示：Shift、Caps Lock、方案快捷键、候选数、原生横排、注音位置。
- 输入方案：启用、排序、版本、作者、依赖与配置来源；缺失但已启用的方案不会被静默删除。
- 万象输入：全／双拼、简繁、纠错、上下文、模糊音；独立场景快捷短语。计算等沿用已安装方案的 Lua 组件。
- 按键与标点：按作用范围编辑 Rime 按键列表及全半角映射。复杂列表和映射目前使用 YAML 编辑，不提供拖拽设计器。
- 词库与模型：静态词库 TSV 合并、.gram 导入扫描、具备 grammar 配置的方案模型选择、官方用户快照生成。
- 皮肤：搜索、导入、变体预览、启用、导出、版本回退、恢复原生默认。
- 场景、备份、同步、诊断：复用既有独立学习、官方快照合并和先采集现场的流程。

每个输入设置显示作用范围和来源。全局读取 `default.custom.yaml`、编译配置及原始默认；指定方案先读取该方案覆盖与方案配置。只有改动的选项进入保存计划。编译资料只读；不适配的配置结构显示说明。

## 保存与应用

1. 选择配置目录及全局／具体方案，点击“载入”。
2. 修改输入设置，点击“预览修改”审阅修改前后内容。
3. “保存设置”生成原文件备份、恢复索引和变更记录，不自动部署。
4. “部署应用”才调用安装目录内官方部署器；隔离预览模式禁止此动作。

配置在载入或审阅后被其他程序修改时，拒绝覆盖，要求重新载入。未知补丁与不相关设置保持；YAML 注释／排版可能被序列化改写，原字节仍可从备份恢复。初次新增配置的回滚会在预览中明确标出待移除文件，用户确认后才执行，并先备份当前文件。

恢复配置只从本用户目录的工具备份读取，恢复前也备份当前资料。场景快照恢复由官方 Rime 同步机制合并，不复制活动 `.userdb`。

## 显示偏好与皮肤

`display.json` 与 `state.json` 分开存储。v2 显示偏好包括 `annotationEnabled`、`annotationPosition`（`skin` / `above` / `beside`）、`emptyAnnotationMode`（`collapse` / `reserve`）、`fontMode`（`user` / `skin`）、`fontPoint`、`commentFontPoint`、`density`（`compact` / `standard` / `skin`）。旧 v1 的 `hidden` 读取为关闭注音，保留旧皮肤字号和密度，读取不会改写旧文件。明确的用户偏好优先于皮肤及旧版样式覆盖。

默认位置、字号和密度均跟随原配置／已选择的皮肤。未选择扩展皮肤时保留小狼毫从 YAML 读到的配色、字体、排列及原有候选后侧注释；不会自动启用上方注音或 12／10 pt 的字号覆盖。12／10 pt 是主动启用自定义字号时的编辑初值。紧凑密度的文字间距／内部留白／注音行距为 8／4／2 DIP，标准为 12／6／3，均需主动选择。无注音的候选保留同一文字基线；上方注音支持整行无注音时收起或保留高度，隐藏时不绘制分隔线。详见 [默认外观兼容记录](DEFAULT-APPEARANCE-20261025.md)。

候选显示使用单独“保存并刷新候选显示”按钮，不进入输入方案部署。没有皮肤包时也能应用。刷新失败恢复原文件字节；服务关闭时显示“已保存待刷新”。托盘“输入法设定”打开安装目录 `SettingsCenter` 下的新设置中心；“高级 → 传统方案设置”保留原窗口。重复打开会激活已有设置中心。

“万象输入”的“万象长词注音”单独修改当前方案的 `super_comment/candidate_length` 为 64，必须预览、备份、保存后再部署。只对提供该字段的万象版本启用，工作／日常需分别设置；不修改其他补丁，不猜测缺失读音。系统应用自行绘制候选窗不保证呈现原生皮肤。

新界面不提供图片布局、边框或配色编辑；这些功能由独立离线网页设计器提供。皮肤包和变体均从清单读取，不限制为守岸人的三个变体。附加“简洁纯色”包用于无角色布局示例，不自动启用。

## 候选窗位置

“通用与候选显示 → 候选窗位置”默认“小狼毫原有定位”（`candidatePlacement: "native"`），沿用原定位分支，附加偏移／间距／图片避让不参与计算。主动选择自动避让／优先上方／下方时，才启用这些参数，单位为 96 DPI 逻辑像素，仅作用于原生横排候选窗。旧文件明确保存的 `auto`／`above`／`below` 保留原含义；缺省字段使用原定位，不改写旧文件。空间不足自动换边，超出屏幕工作区的超大皮肤可能无法完全避让。

“预览位置（使用未保存参数）”使用当前启用皮肤与唯一临时显示偏好，绘制模拟输入行并由真实原生候选窗定位；关闭后清理临时文件。预览不连接日常算法服务，不写入活动显示偏好。保存只刷新外观，位置在下次候选窗显示时生效。

排查偶发图片不加载时，诊断包会同时收集 `presentation-<PID>.log`：`host_selected` 表示宿主选择代绘，`native_selected` 表示允许本体显示。该信息与已有解码日志配合使用，不能单凭一个状态判断历史故障全部修复。

## 扩展入口

- `SettingsPageRegistry.Register` 注册模块描述及页面工厂。
- `ISettingsPage` 统一未保存状态、修改预览和保存完成入口。
- `RimeSettings` 管理通用补丁、校验及来源；`RimeProfiles` 管理万象专属设置与场景。
- 皮肤继续遵循版本化 `.rimeskin` 格式。方案及 Lua 仍由 Rime 处理；没有新增第三方程序插件宿主。

## 独立验证

管理程序支持 `--data-root <皮肤目录> --rime-root <测试配置目录> --preview-mode`。该模式不连接日常算法服务；仍可以保存隔离目录中的配置。`--ui-smoke` 遍历所有模块与方案作用范围，退出码不为零表示页面加载失败；`--capture-image <PNG>` 导出真实 WPF 布局图。

原生预览不加载算法服务，支持不传皮肤参数、纯配色和角色皮肤。`--display-preferences <完整路径>` 读取隔离显示偏好。`--preferences-test` 使用当前进程内的临时 LOCALAPPDATA 验证优先级、旧版覆盖及加载失败不修改外观。`--layout-test` 检查 96／120／144／192 DPI 的候选边界及注音基线；`--redraw-test true` 检查真实分层窗口提交、重复刷新及图片加载失败时的画布保留。自动测试不等同于人工观察无闪烁和跨屏实测。

独立预览模拟 TSF 行内编码：候选框只显示每个候选的注音和文字，不再额外显示整段 `shou'an'ren`。实际输入时编码由应用输入区显示；不支持行内编码的旧应用继续使用 Rime 原有的编码显示回退，避免丢失正在输入的编码。

原生图片诊断记录重绘原因、资源数量、画布、DPI、线程与 GDI+ 初始化状态；失败时附图层序号、加载／像素复制阶段、GDI+ 错误和只读文件访问错误，不记录输入文字或图片路径。日志位于 `%LOCALAPPDATA%\ShorekeeperWeasel\render-logs`，单进程文件超过 128 KiB 轮换一次。独立预览使用临时日志目录。此诊断帮助排查图片消失；“问题1”的根因仍需独立调查。

GitHub Actions 必须生成 x86/x64 成套组件、安装包、自包含面板、原生预览、皮肤包及 SHA256 清单。发布 Release、安装实验构建、连接真实 WebDAV 与 Android 实机验收另行授权。


## 离线皮肤设计器

皮肤页的「打开离线皮肤设计器」打开同安装目录 `SettingsCenter/Designer/index.html`。完整构建同时提供 `rime-skin-studio.zip`，可单独解压离线使用。设计器支持图片图层、锚点拖动、九宫格、变体、带／无候选注音两种预览，导出 .rimeskin 后再导入设置中心；网页不会连接日常输入法。

格式 1.1 的皮肤可声明仅无注音或两种均支持；需含该能力支持的成套新构建。默认资料和开机启动不依赖开发工具；本轮不安装到日常环境、不迁移本机遗留资料。
