# 候选窗定位与皮肤显示诊断

## 本轮范围

仅调整原生横排候选窗的位置和预览，补充 TSF 候选窗归属诊断。沿用现有 GDI 后端；不合入实验 DComp 分支、不改输入方案及学习数据。

## 定位修正

旧路径按文字框定位，上方图片仍可穿过正在输入的文字；还会把调整后的坐标写回输入矩形。新横排路径保存未经调整的光标／组合矩形，按可见框体和装饰在窗口中的实际坐标计算位置，刷新不改写原始锚点。

- 文字框默认位于输入行下方，间距 6 个逻辑像素。
- 可设水平偏移 −256～256、间距 0～128、优先上方／下方；空间不足自动换边。
- 默认启用图片避让。只计算与输入矩形横向相交的图片矩形，右侧未相交的角色不会无故扩大垂直间距；靠屏幕边缘水平夹紧后重新判定相交。
- 图片的透明区域仍按整张图片矩形保守避让，不逐像素扫描 Alpha。窗口比屏幕工作区更大时只能尽量保留可见范围，无法保证所有内容都不遮挡。
- 位置字段在 `display.json`，不进入皮肤清单、不改变图片相对框体的锚点，也不增加 UIStyle 序列化字段。
- 小于 6 个物理像素的同一输入矩形竖向抖动保留上次接受的锚点；后续刷新不会绕过这一防抖。创建窗口前传入的坐标及预览路径会保存并在创建后重放。
- 原生窗口每次由隐藏转为显示时载入一次位置偏好；输入过程中不逐键读取该文件。保存后在下一次候选窗显示时生效；无效文件保留上一份有效参数。
- 竖排、状态图标与全屏布局沿用原定位逻辑。

## 设置与预览

“通用与候选显示 → 候选窗位置”可调整参数。“预览位置（使用未保存参数）”会生成唯一临时快照，使用当前启用皮肤打开独立原生预览；不写入活动显示偏好、不连接 Rime 会话。关闭预览后清理本次临时文件。

预览绘制模拟输入行 `shou'an'ren │`，原生候选窗以该行的屏幕矩形定位。可拖动预览窗口观察边缘换边；实际应用传入的矩形可能不同，不能以模拟预览证明所有宿主定位都正确。网页设计器继续设计框体内相对布局，仅兼容导入新增显示偏好，不模拟操作系统光标定位。

## 图片消失诊断

新增限长的 `render-logs/presentation-<PID>.log`（128 KiB 轮换，保留一份 previous），与已有图片解码／重绘日志一并由设置中心采集。

- `host_selected`：BeginUIElement 返回不显示本体窗口，宿主接管候选 UI；该路径不承诺绘制图片装饰。
- `native_selected`：宿主允许本体显示，同时记录本体窗口是否实际创建、请求图片数量。
- `begin_failed`：记录 HRESULT；`show/hide` 仅记录显隐转换。

日志不记录输入文字、候选内容、光标坐标、图片路径或账号凭据。新增日志用于区分原因，**不代表已复现或修复用户偶发图片消失**，也不以挂钩强制覆盖系统候选窗。

## 验证

- 几何回归：旧规则的遮挡反例、装饰避让开关、右侧非相交图片、屏幕夹紧后相交、上下边缘换边、负坐标显示器、超大窗口，以及 100%／150%／200% 几何比例。
- 原生隔离预览：连续刷新与隐藏再显示不改变光标锚点、位置解析及无效参数保留前值；纯色和图片皮肤分别运行。
- 显示中与系统／宿主直接隐藏 HWND（不改变 UI 状态）时的连续更新不重新解析位置文件；窗口销毁重建仍保留预览路径和原始输入位置。
- 托管回归：默认值、旧文件兼容、参数边界、保存往返与刷新失败回退。
- 网页回归：接受新的偏好导出，位置参数不写进皮肤样式、不改变图片相对布局。
