# 萌娘词库与万象字表的编码兼容性待适配

状态：已记录，交由高级模型评估；本轮停止该数据适配的修复尝试。订阅页面保留下载、导出及严格校验，不宣称所有萌娘词条可直接启用。

## 证据

- 公开来源 `suiginko/moetype` 的最新 Release 元数据为 20260912；本机隔离样本来自仓库 `main` 的 `moe.dict.yaml`，表头版本 0.3.7、文件 8,078,186 字节，解析得到 204,330 条词条。未将文件大小相同当作 Release 资产内容完全一致的证据。
- 与 `amzxyz/rime-wanxiang` 的 `wanxiang` 分支 `dicts/zi.dict.yaml` 比较，来源编码有 52 种未出现在该字表中。包括未带声调的 `bao`、`bing`、`shou`、`ren`，以及 `rōng`。没有自动替换、猜读音或修改源文件。
- 隔离目录 `.tools/dictionary-subscriptions/compat` 仅下载主方案、主词典表头与字表。实际启用预览继续检查 `dicts/jichu` 时因未下载该文件被明确拒绝；没有保存启用补丁。
- 因此目前能确认“字表与扩展词库并非完全一致”，不能把该部分资料的拒绝等同于完整万象环境的确定失败；也不能据此声称每个缺失编码都是错误读音。

## 复现入口

1. 在独立资料目录放入目标万象版本的完整方案、词库源码，不使用日常资料。
2. 订阅页面下载上述带调词库，在该方案上预览启用。
3. 对照 `DictionarySubscriptions.RequireCompatible` 记录缺失编码和具体词条；必要时通过真实 Rime 独立部署验证 packs 编译与检索。

## 影响与未确认事项

- 页面可下载、显示版本并导出该词库；编码不匹配时不写入挂载补丁。已验证匹配的小型词库可正常启用。
- 不确定完整目标万象各版本的音节表能容纳多少缺失编码；不同辅助码版本另需适配。
- 请评估采用维护者已有适配产物、经确认的编码转换，还是让用户明确审阅后跳过不兼容词条。不能按逐字默认读音无条件重写角色名。
- 验收须覆盖多音字、名称符号、辅助码、升级后的再次适配、原始来源追溯和失败回退；不得覆盖个人补词或活动学习数据库。
