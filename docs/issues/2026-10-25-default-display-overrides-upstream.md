## 用户目标

默认打字表现延续原有小狼毫／输入方案配置，增强能力由用户主动选择。用户所指的 Win11 外观在本机来自万象 `weasel.yaml` 的 `win11_light`／`win11_dark`，不是官方仓库的 Aqua 默认配色；不应以恢复默认为由改回竖排或重置方案。

用户随后明确：不需要“继承原外观并叠加图片”的第三种模式。兼容目标是原有小狼毫 YAML 外观配置及新 `.rimeskin` 皮肤包可以继续分别使用；选择原有配置时，应保留其配色、字体、布局及注释显示语义，不强制转换新包格式，也不被未主动启用的扩展默认值覆盖。原有外观配置属于小狼毫前端，Rime 核心不负责外观渲染。本需求不新增图片叠加模式或相关设计器能力。

## 实际证据

- `manager/Shorekeeper.Core/DisplayPreferences.cs` 的默认值为注音启用、上方、用户字号 12／10、紧凑密度。
- `WeaselUI/SkinPackage.cpp` 的 `LoadDisplayPreferences` 在文件不存在时使用空对象，仍应用上述注音、字号和留白默认值。
- `LoadActiveSkin` 在没有活动扩展皮肤时仍调用该偏好加载；因此“无扩展皮肤”不等于“完全跟随原来的小狼毫配置”。
- 设置中心“恢复默认显示参数”构造 `new DisplayPreferences()`，会再次选择改版默认值。现有位置选项支持上方／旁边／跟随皮肤，取消“显示候选注音”可隐藏；但默认跟随 Rime 配置与跟随皮肤的来源提示尚未明确区分。
- 本机 `RimeData/weasel.yaml` 使用 `win11_light`／`win11_dark`；`weasel.custom.yaml` 保留横排补丁。官方 `upstream/master:output/data/weasel.yaml` 则为 `aqua`、`horizontal:false`。两者不可混为一个默认。

## 待实现契约

1. 默认沿用原有 Rime／小狼毫基础样式，不自动选角色皮肤、不额外覆盖字号、留白、横竖排列。
2. 将方案已有注释与增强注音区分。原版按方案提供的注释显示，并非一律生成拼音；延续原行为应将已有注释放在候选后侧，不主动启用两行布局或长词注音增强。
3. 提供跟随原配置／上方／候选后侧／隐藏等清楚选项，区分皮肤默认与用户覆盖。仅刷新外观的选项不得触发方案部署；注音生成等方案参数仍需备份、差异预览及明确部署。
4. 恢复默认外观不得重置输入方案、简繁、词库或学习数据；已有明确选择的皮肤与覆盖参数不应在升级时被静默清除。是否另设“一键恢复原版外观”由后续需求确认。
