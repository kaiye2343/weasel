## 分工和执行规则

- Codex：查阅实际代码、确定接口和精确修改方案；完成网页及设置中心前端；指导、审查 DSH 的实际 diff，运行验证，管理 Git 和 Actions。

- 各批次独立限定可写文件。存在文件交叉时串行执行；不得为了并发拆出重复架构。
- DSH 不提交、推送、安装依赖、运行日常服务、修改真实用户数据、修改 AGENTS 或再次委派。产物必须由 Codex 验收。

- 保持 `workspace-write / ask`。单次任务运行记录位于忽略目录；不得将凭据、模型输出或私人诊断提交到 Git。
- 每批通过后进行功能提交；推送到 fork 已获授权。完整 CI 失败时先修复该批，不继续叠加依赖它的新功能。
- 图形自动回归由隔离 CI 执行，日常桌面操作由用户完成。安装与真实账号连接仍需单独授权。
