## 共同边界

- 遵循仓库 AGENTS.md：发现新的独立问题，先在 `docs/issues/` 建单并停止该问题的修复尝试，交用户调用高级模型处理；可继续无依赖的工作。
- 保留既有未提交修改。代码探索优先使用 CodeGraph；实际 diff、构建和测试仍需核验。
- 不操作用户桌面、键鼠或输入法做测试；实机交互由用户本人完成。安装实验构建、发布 release、迁移日常资料及真实账号连接须另行授权。
- 配置写入须先备份并预览变更，保留无关补丁；保存与部署分开。不得触碰活动学习数据库。
- 修改 UIStyle 序列化时须成套构建前端、服务和部署器。构建、自动回归与用户实机验收分别报告。
