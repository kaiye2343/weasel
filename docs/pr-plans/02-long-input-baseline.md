# PR 02：长串输入性能基线

状态：待开始｜优先级：P1｜依赖：无

## 目标与范围

在隔离环境建立可重复的长串输入测量，作为后续优化依据。先核对既有探针、调用栈和测试，复用已有接口；明确输入样本、方案与词库版本、运行条件、预热、重复次数、P50/P95 和候选结果记录。分别报告核心、通信和绘制中实际可测的阶段，不能测量的阶段明确标注。

覆盖不同长度、短串对照和具有代表性的输入；保持学习数据隔离，不记录用户输入正文。不要调整日常方案或用关闭能力换取跑分。

## 验收

- 同一环境可重复运行并保留版本、方法、原始或汇总结果和限制；统计方法明确。
- 候选结果有可比较基线，且性能指标不冒称桌面端到端延迟。
- 运行适当的隔离自动化；记录无法执行的阶段及原因。
