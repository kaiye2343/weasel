# PR 04：词库兼容性验证与方案

状态：待高级模型接手｜优先级：P1｜依赖：既有问题单

## 目标与范围

由用户调用高级模型接手 [萌娘词库与万象编码兼容性问题](../issues/2026-10-25-moetype-wanxiang-code-compatibility.md)。在隔离资料目录核对完整目标方案及版本，确认具体词条、编码差异及真实部署／检索结果；区分样本字表差异与完整环境实际失败。

评估已有适配产物、经确认的转换、用户审阅后跳过等选择，比较数据来源、准确性、升级和回退。不要猜测读音、覆盖个人补词或操作活动学习数据库。

## 验收

- 记录来源、版本、复现步骤、实际证据及未确认项；结果可由接手者复核。
- 形成可审阅的处理方案与待用户确认的产品取舍；不把下载／解析成功当作完整挂载成功。
- 本计划本身不解除项目对既有问题的接手限制，也不授权修改日常资料。
