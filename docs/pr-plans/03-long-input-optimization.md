# PR 03：长串输入热点优化

状态：待开始｜优先级：P1｜依赖：PR 02 的可复现基线及热点证据

## 目标与范围

针对测量确认的具体热点提出最小改动，先核对调用链、现有上游实现和影响范围；若热点位于外部核心或当前仓库无法安全修改，记录结果并重新评估，不强行引入优化。保持输入语义、学习能力和配置兼容。

## 验收

- 使用 PR 02 相同样本和环境进行重复前后对照，报告 P50/P95、资源开销及波动；保留无收益结果。
- 对约定语料比较候选内容与顺序，验证边界、失败路径和相关回归；不能以结果减少或关闭功能制造收益。
- 解释实际修改和证据边界；不把隔离测试结果称为用户桌面端到端体验。
